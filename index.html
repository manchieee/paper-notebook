日本株スイング紙トレ ルール（まさみ編集用）

このファイルは毎朝の銘柄選定時に全文をAIへ渡す。変更したルールは次回の選定から反映する。
これは紙（仮想約定）専用で、実発注・証券API接続・通知は行わない。

資金と建玉

  • 仮想資金は5万円で開始する（小銭から稼ぐスタイル）。
  • 1銘柄の取得金額は1万円を上限とする。1株単位（単元未満株相当）で買う。
  • 同時建玉は最大5銘柄とする。
  • 新規選定は1日最大4銘柄とする。

入口

  • 出来高が平常時より急増し、直近高値や抵抗帯を上抜けた銘柄を優先する。
  • 上場から1年未満の銘柄は除外する。
  • 株価100円未満の銘柄は除外する。
  • 株価1,000円超の銘柄は除外する（低位株専門。高い株は買わない）。
  • 当日の上昇率が+50%を超えた銘柄は追いかけない。
  • 候補データに無い価格・時刻・出来高・上場日を推測で補わない。不明な値は不明として扱う。
  • 条件に合う銘柄が無い日は「選定なし」でよい。

出口（プログラム固定）

  • エントリー価格から-8%で逆指値の仮想決済。
  • +10%到達後は、到達後の最高値から-5%でトレーリング仮想決済。
  • 10営業日経過で時間切れの仮想決済。
  • 手数料は往復0.2%（買い0.1%・売り0.1%）を控除する。

AIの役割

  • AIは候補から最大4銘柄を選び、理由と想定保有日数をJSONで返す。
  • AIは売買を実行しない。本人もこのパイロットの出力を実発注として扱わない。
  • AIが不調、JSONが不正、または根拠が弱い場合は安全側で「選定なし」とする。
📖あかりR / 権利付き最終日 / PEAD のルールconfig/jp_anomaly_rules.md

日本株アノマリー紙トレ ルール（まさみ編集用）

このファイルは3手法（あかりR / 権利付き最終日 / PEAD）の運用ルールを明文化したもの。
変更したルールは次回の選定から反映する（コード側の定数は core/jp_anomaly_paper.py の STRATEGIES）。
これは紙（仮想約定）専用で、実発注・証券API接続・入金・通知は一切行わない。
あかり本体（core/jp_swing_paper.py / config/jp_swing_rules.md）は変更していない（並走比較のため）。

全戦略に共通

  • 仮想資金は戦略ごとに独立して5万円で開始する（あかりと同額）。
  • 1銘柄の取得金額は1万円を上限とする。1株単位（単元未満株相当）で買う。
  • 手数料は往復0.2%（買い0.1%・売り0.1%）を控除する。あかりと同じモデル。
  • 価格・出来高・上場日・配当・適時開示は全てAPI/公開ページの実測。取れない値は「不明」として扱い、推測で埋めない。不明が残る銘柄は除外側に倒す。
  • 条件に合う銘柄が無い日は「選定なし」でよい。
  • 上場から1年未満の銘柄は全戦略で除外する。
  • 流動性の床：直近20営業日の平均出来高が 50,000株未満は除外する。

    • ※この5万株という数字に出典はない。うちで決めた床。変えたければここを直す（コード側 LIQUIDITY_MIN_AVG_VOL）。

約定モデル（あかりとの唯一の構造的な差分）

あかりは 08:45 時点の気配値でそのまま仮想約定する。
この3手法はいずれも「寄り（始値）で買う」ことが根拠そのものなので、次の2段階にしている。

  1. select（平日 08:46）＝候補抽出と選定だけ。建玉は作らず「約定予約（pending）」に積む。
  2. update（平日 15:46）＝その日の実際の前場始値（Yahoo chart APIの日足 open 実測）で仮想約定する。

始値が取れない銘柄は約定させない。3営業日取れなければ予約を取り消す。
このため「あかり vs あかりR」の比較では、約定価格の作り方が違う点を差し引いて読む必要がある。

出口の判定タイミング

  • 損切りと時間切れの判定は 1日1回（15:46 の update）・終値ベース。ザラ場中の逆指値は模擬していない。
  • したがって「-10%で損切り」は「終値が -10%以下になっていたらその終値で決済」の意味。

1. reversal（あかりR・逆張り）

入口

  • 前営業日の終値が、前々営業日の終値比で -7%以下に下落した銘柄。
  • 株価100円以上1,000円以下。
  • 上場1年超。
  • 前営業日の出来高が、その直前20営業日平均以上（出来高比 1.00x 以上）。
  • 固有悪材料の除外：前営業日15:00以降〜当朝までの適時開示（TDnet 適時開示情報閲覧サービス

    • https://www.release.tdnet.info/ の日次一覧）を読み、次の語がタイトルに含まれる銘柄は除外する。

    `下方修正 / 減額修正 / 特別損失 / 減損 / 不適切 / 訂正 / 上場廃止 / 監理銘柄 / 特設注意 /

    債務超過 / 民事再生 / 破産 / 会社更生 / 課徴金 / 行政処分 / 業績予想の修正 / 配当予想の修正 /

    無配 / 不正 / 調査委員会 / 内部統制`

    • 「業績予想の修正」はタイトルだけでは上下が判別できないことが多いので、上方修正と読める語（上方修正・増額修正）が同じタイトルに無ければ悪材料扱いにする＝除外側に倒す。
    • TDnetが取得できなかった日は、その銘柄を全て除外する（不明なら買わない）。
  • 1日最大3銘柄。同時建玉は最大5銘柄。
  • 適格が多い日は、下落率が大きい順に採る。

出口

  • 5営業日後の終値で仮想売り（根拠にした検証の条件に合わせる）。
  • 安全弁として -10%（終値ベース）で仮想損切り。

根拠（出典と数字）

  • ギャップダウン後の反発（東証2000-2024・157万件）：-2%以上の寄り付きを始値買い・5日後終値売り。

    • -7%以上で勝率57.8%・平均+3.37%。

    https://www.systemtrade-kabu.com/gap-down-rebound/

    → 査読なし・手数料明記なし。

  • 短期リバーサルの日本実証：Chang, McLeavey & Rhee (1995) / Gunaratne & Yonezawa (1997)

    • 年率約11%（東証1955-1990・サンプルが古い）。

  • 日本はモメンタムが弱い／効かない市場との報告（ABEF 2022）

    • https://www.abef.jp/conf/2022/common/doc/oral/2B02.pdf

  • ギャップアップ当日買いの不利（＝あかり側の弱点。東証2000-2025・168万件）：

    • +7%以上のギャップアップを始値買い・終値売りで平均-1.59%・勝率24.2%、翌日終値まで持って+0.34%・勝率40.6%。

    https://www.systemtrade-kabu.com/gap-up-next-day/

    → 査読なし・手数料なし。

再現性についての注意（調査時の本体判断をそのまま転記）

この検証は「寄り付きがGDだった銘柄」を始値で買う＝朝7時時点では寄りが分からないので、そのままは再現不可。
再現可能な近似＝「前日終値ベースで-7%以上下落＋固有悪材料なし」を翌朝寄りで買う。
効果の大きさは別物として紙トレで測る。

2. kenri（権利付き最終日）

権利日の決め方

  • 権利確定日 = 月末（月末が非営業日ならその月の最終営業日）。まず「月末が権利確定日」の銘柄を対象にする。
  • 権利付き最終日 T = 権利確定日の2営業日前。権利落ち日 = T の翌営業日。
  • 営業日は自前計算する。祝日は内閣府「国民の祝日について」CSV

    • （https://www8.cao.go.jp/chosei/shukujitsu/syukujitsu.csv ）を一次情報として取得し

    data/jp_holidays_cao.json にキャッシュする。これに加えて JPX の休業日 12/31・1/2・1/3 を足す。

  • 祝日カレンダーが取れない場合は権利日を計算しない＝選定なしにする。
  • レポート（data/jp_anomaly_report_latest.md）には常に「次のT」を出す。

次回：T = 2026-09-28（月）／権利確定日 2026-09-30（水）／権利落ち日 2026-09-29（火）。
買い予定日 T-1 = 2026-09-25（金）。
→ T-1（金）から T（月）までの間に週末を跨ぐ。土日の持ち越しになる点は承知の上で、紙なので実行する。

入口

  • T-1 の寄り（前場始値）で仮想買い。
  • 対象：Yahoo で配当利回りが取れる銘柄のうち、権利落ち日（exDividendDate）が上で計算した権利落ち日と一致する銘柄を、配当利回りの高い順に。
    • 権利落ち日が取れない／一致しない銘柄は除外（決算月を推測で埋めない）。
  • 株価100円以上1,000円以下、20日平均出来高 50,000株以上、上場1年超。
  • 最大5銘柄。

出口

  • T の後場寄り（12:30） で仮想売り。権利落ち日は跨がない。
  • 12:30 の始値は5分足の実測（Yahoo chart API）。取れなければ決済せず次回の update で再試行する。
  • 保有が1.5営業日と短いので損切りは置かない。

根拠（出典と数字）

  • 権利付き最終日効果（東証4083銘柄・45万件）：

    • 権利付き最終日 平均+0.443%・勝率60.7%、権利落ち日 平均-0.244%・勝率44.4%（3月は-1.528%）。

    https://www.systemtrade-kabu.com/ex-dividend-anomaly/

    → 査読なし。

  • 未確認点：権利付き最終日効果の定量的な査読研究は未発見（2026-09-04時点）。

3. pead（決算後ドリフト・紙の別枠）

この戦略は「週末を跨がない」という運用ルールの適用外（20営業日保有なので週末は必ず跨ぐ）。
まさみ承認済みの別枠として、紙でだけ回す。

入口

  • トリガー＝前営業日15:00以降に適時開示で「上方修正」または「増額修正」を出した銘柄（TDnet日次一覧のタイトル一致）。
  • SUE（決算サプライズ）は計算しない。上方修正IRを代理指標として使う（決算数値の取得と標準化はしない）。
  • 株価100円以上3,000円以下、20日平均出来高 50,000株以上、上場1年超。
  • 翌朝（＝開示を検知した当日）の寄りで仮想買い。
  • 1日最大2銘柄。同時建玉は最大6銘柄。
